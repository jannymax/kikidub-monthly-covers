KikiDub 月度封面配置维护

本仓库独立管理月度专辑配置和自定义分层 PNG。支持此能力的 App 首次发布后，新的插画、字体和构图可以直接发布到仓库，日历入口、黑胶标签和报告首图同步使用完整封面。现有六月设计已作为六层示例接入。

一、发布自己的设计

1. 从设计工具导出透明 PNG 图层；字体可转为图形后随图层导出。使用 8-bit 静态 PNG，每层最大 2048×2048、2 MB，每张封面最多 12 层、8 MB、8,388,608 个去重像素。建议裁掉图层无用透明边缘，减小内存占用。
2. 参考 examples/june-design.json 编写 design.json，把每层 file 改为导出 PNG 的路径（相对于 design.json，或绝对路径），设置 frame 和动效。数组从底层到顶层排列。
3. 运行准备工具，自动整理不可变素材文件名、生成 SHA256/字节数并更新目录：

   python3 tools/prepare_cover.py /你的路径/design.json --month 2026-11 --revision 2026-11-01.1

   可加 --dry-run，仅检查、不写文件。没有全部通过校验时不会替换当前目录。
4. 发布前检查：

   python3 tools/validate_covers.py
   python3 -m unittest discover -s tools -p 'test_*.py'

5. 把 monthly-album-covers.json 和 assets/ 一起提交并推送到 main。PNG 已使用内容哈希命名，应添加新文件，不覆盖旧文件；也不要遗漏配置引用的图片。

二、自定义图层字段

目录 schema_version 仍为 1；revision 每次发布更换。covers 保留原生模板，用于旧客户端回退；layered_covers 按完整年月 YYYY-MM 保存自定义封面。旧客户端会忽略 layered_covers，继续使用原生模板。

自定义封面：background 为背景色，label_ink 为黑胶中心月份数字颜色（六位十六进制，不带 #）；layers 为图层数组。

每层包含：
- id：唯一标识；file：准备工具的输入 PNG 路径，工具会替换为 asset.path/sha256/byte_count。
- frame：x/y/width/height，相对正方形封面的归一化比例。x/y 范围 -0.15...1，宽高 0.005...1.2，允许局部裁切。
- rotation（可选）：-180...180 度；opacity（可选）：0...1。
- motion（可选）：type 为 float（上浮）、sway（摆动）、pulse（轻呼吸）、slide（水平轻移）；amount 为幅度，sway 使用角度 0...8，其余使用比例 0...0.08；anchor 可设 x/y（0...1），默认居中。
- blinks（可选）：true 时该图层短暂闭合再展开；适合裁切后的独立眼睛图层。角色和眼睛需要同步浮动时，两层设置相同 float 幅度。

所有微动效只轻动一轮后停稳，应用回到前台或封面切换时可重播；系统减少动态效果开启时显示静态封面。全新的代码级动效类型仍需 App 增加支持，组合现有动效和任意 PNG 插画无需发版。

自定义 PNG 内的月份文字由设计者保证与年月键相符；App 的报告标题、封套底栏和黑胶中心月份仍按实际年月/界面语言生成，不会读取图片文字。

三、原生模板字段

covers 中每项包含 motif（sprout/echo/orbit/ribbon）、palette（background/ink/first_digit/accent）、first_digit_frame、second_digit_frame、mascot_frame 和 zero_thickness（0.03...0.35）。原生模板数字始终由 App 根据实际月份生成。

四、更新、缓存和回退

固定目录地址：https://raw.githubusercontent.com/zhizuzhefu/kikidub-monthly-covers/main/monthly-album-covers.json

目录成功更新后，当地自然日内不再重复刷新；失败至少间隔五分钟重试。图片按当前查看的封面加载和缓存，全部图片通过校验后才替换之前的完整封面。缺图、断网、哈希错误、超限时保留完整旧版本；没有完整缓存时使用原生模板。

缓存按 SHA256 区分素材版本；内存最多保留两张解码后的完整封面，磁盘最多保留 24 张完整封面、约 64 MB 图片，系统也可能清理缓存。发布到 Git 后可能有传播延迟，不保证所有设备立即切换。

回退某个月时，可发布之前的 layered_covers 条目；删除其 layered_covers 条目则恢复该月原生模板。发布合法的空 covers 与 layered_covers 对象则恢复全部内置设计。

五、实际客户端校验（在相邻 App 仓库）

cd ../kiki-dub-main
swiftc -swift-version 5 KikiDub/Core/Models/ReportMonth.swift KikiDub/Core/Models/MonthlyAlbumCoverCatalog.swift KikiDub/Core/Models/MonthlyAlbumLayeredCover.swift KikiDub/Core/MonthlyAlbumCoverAssetStore.swift KikiDub/Core/MonthlyAlbumCoverRepository.swift tools/monthly_album/check_monthly_album.swift -o /tmp/kiki-check-monthly-album
/tmp/kiki-check-monthly-album ../kikidub-monthly-covers/monthly-album-covers.json

发布后加 --live 可验证真实 GitHub 目录、分层 PNG 下载和离线缓存恢复。
